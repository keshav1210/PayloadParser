How to open a JSON file in Excel

Published 22 October 2026 · 5 min read · By the JSON XML Editor team

Excel doesn't open .json files with a double-click the way it opens CSV, but there are three reliable ways to get JSON data into a spreadsheet. Which one is best depends on your Excel version and how nested the data is.

1. Power Query: Data → Get Data → From JSON

Excel for Microsoft 365 and Excel 2016 or later on Windows can import JSON with Power Query:

  1. Go to Data → Get Data → From File → From JSON and pick the file.
  2. The Power Query editor opens. If the file is a list, click To Table (accept the defaults).
  3. Click the expand button (two arrows) in the column header and choose the fields you want. Repeat for nested objects.
  4. Click Close & Load. The data lands in a table, and Refresh re-reads the file later.

This is the best choice when the same JSON file is updated regularly. Menu names differ slightly between versions, and on a Mac the JSON connector depends on your Excel version; if you don't see it, use one of the next two methods.

2. Convert JSON to an Excel file online

Paste the JSON into the Excel converter and download an .xlsx workbook. It works in any Excel version, including Excel for Mac and Excel on the web, and the conversion runs in your browser, so the data stays on your computer.

3. Convert JSON to CSV, then open the CSV

The JSON to CSV converter flattens nested fields into columns such as address.city, so every value gets its own column. Download the CSV and open it in Excel, Google Sheets or LibreOffice.

What works best for which JSON

Your JSONBest method
An array of flat objects ([{"id":1,"name":"Ada"}, …])Any of the three
Nested objects (address.city)JSON to CSV (flattens automatically) or Power Query (expand each level)
Arrays inside each record ("tags": ["a","b"])Power Query (expand to new rows) or decide how to join them first
A file that changes every dayPower Query, so you can refresh
A one-off paste from an API responseOnline converter

Common problems

  • "We found a problem with some content" or nothing loads: the JSON is probably invalid. Check it with the JSON validator first.
  • Long numbers turn into 1.23E+15: Excel shows numbers with more than 11 digits in scientific notation and keeps only 15 significant digits. Format ID and phone columns as Text.
  • Accented characters look wrong in CSV: open the CSV through Data → From Text/CSV and pick UTF-8, or use the .xlsx route.
  • You only need one part of a big file: explore it in the JSON viewer and copy just that array.
