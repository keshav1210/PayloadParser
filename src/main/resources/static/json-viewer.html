How to view JSON as a tree

  1. Paste JSON into the editor, or drop a .json file on it.
  2. Click View. The right-hand panel shows the data as a tree; switch between Tree View and Text View at any time.
  3. Click the arrows to expand or collapse objects and arrays.

Find what you're looking for

  • Search with Ctrl+F highlights every match in keys and values.
  • Copy path gives you the location of a value, for example $.orders[2].items[0].sku, ready to use in code, tests or JSONPath.
  • JSONPath queries such as $..email or $.items[?(@.price > 100)] pull out just the values you need.
  • Folding in the text editor collapses blocks while keeping brackets visible, and clicking a bracket highlights its partner.

Useful for API responses and logs

API responses and log payloads are often one long line with dozens of nested levels. The tree makes the structure visible at a glance: which fields exist, which arrays are empty and where a value sits. When you've found the part you need, format, minify or convert it to CSV, XML or YAML from the same page.

Private and exact

The viewer runs in your browser, so the JSON you open isn't uploaded. Long numbers such as 64-bit IDs are displayed exactly as written, not rounded.

Frequently asked questions

What is a JSON viewer?

A tool that shows JSON as a tree instead of plain text, so you can expand and collapse nested objects and arrays, search, and see the structure of the data at a glance.

Can I open a JSON file?

Yes. Drop the file on the editor or use the upload button. The file is read by your browser, not uploaded.

How do I get the path to a value?

Use Copy path on a node in the tree view. You get a JSONPath like $.users[0].address.city that you can paste into code or into the query bar.

Does it work with large JSON files?

Yes, files of several megabytes open fine. For very large files, collapse the top level first and expand only the parts you need.

Is my data sent to a server?

No. Viewing, searching and querying all happen in your browser.
