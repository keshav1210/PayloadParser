Compare Two CSV Files

Load an old and a new version of a CSV or Excel file to see what changed: which rows were added or removed, and which cells changed in the rest. Rows are matched by an ID column, so it works even when the files are sorted differently.

    How it works

    1. Add both versions of the file: CSV, TSV, Excel or JSON. They can be different formats.
    2. Pick a key column that identifies each row, such as an ID, SKU or email. Add a second column if one isn't unique on its own (for example order ID plus line number).
    3. Click Compare. The summary counts added, removed and changed rows; the table lists them with each changed cell shown as old → new.
    4. Download the differences as CSV or Excel to share or review.

    Why compare by key instead of line by line?

    A text diff compares line 1 with line 1 and line 2 with line 2. As soon as a row is inserted or the file is sorted differently, every following line looks changed. Comparing by key matches each row with its counterpart wherever it is in the file, so you only see real changes. If your files have no ID column, choose “Row by row” to compare by position. For plain text or code, use the text diff instead.

    Avoiding false differences

    • Ignore extra spaces: "Chicago " and "Chicago" are treated as equal.
    • Ignore case: PRO and Pro are treated as equal.
    • Number formatting: 229, 229.0 and 229.00 are treated as equal, which matters when one file was saved from Excel.

    Columns are matched by name, so the column order doesn't matter. Columns that exist in only one file are listed above the table. Your files are compared in your browser and never uploaded.

    Frequently asked questions

    How do I compare two CSV files for differences?

    Add the old file on the left and the new file on the right, choose the column that identifies each row (such as an ID) and click Compare. You get the added, removed and changed rows, with each changed cell shown as old → new.

    Can I compare two Excel sheets?

    Yes. Both sides accept .xlsx, .xls and .ods files; pick a sheet in each. You can also compare an Excel sheet with a CSV export.

    What if my file has no ID column?

    Choose “Row by row (no key)” to compare rows by position, or choose two columns that are unique together, such as name and date.

    What happens with duplicate keys?

    Rows with the same key are matched in the order they appear, and the tool warns you. Adding a second key column usually makes the match exact.

    Are my files uploaded?

    No. The comparison runs entirely in your browser.
