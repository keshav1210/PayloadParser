About JSON XML Editor

Free tools for the everyday work of developers, testers and data analysts.

Why this site exists

JSON XML Editor started as a JSON and XML formatter for debugging API payloads: paste a response, see exactly where it breaks, fix it, convert it. It has grown into a set of more than 45 tools for the same kind of work, from validating JSON and decoding JWTs to running SQL on a CSV file and explaining cron schedules.

The tools are built by an independent developer who uses them at work, and new ones are added when a task keeps coming up. Every tool is free, with no account and no usage limit beyond basic abuse protection.

How your data is handled

Most tools run entirely in your browser: what you paste never leaves your computer. A few conversions run on our server; there, your input is processed in memory and returned, and it isn't written to a database, a file or our logs. Each tool page says which applies, and the privacy policy has the details, including the one cookie and the analytics the site uses.

Built to be trusted

  • Error messages point to the exact line and column, so you can check every result yourself.
  • The JSON tools keep very large numbers and duplicate keys as written instead of silently changing them.
  • Articles are written from hands-on use of the formats and link to the official specifications they rely on.

Get in touch

Found a bug, a wrong result or a tool you'd like to see? Email jsonxmleditor@gmail.com or use the contact page. Reports with a small example input get fixed fastest.
