One site for everyday developer chores

These tools cover the small jobs that interrupt real work: making an API response readable, turning JSON into a Java class, checking why a cron job didn't fire, decoding a token from a failing request, or generating a batch of test IDs. Each one opens instantly, needs no account and keeps working as you type.

Most tools run entirely in your browser, so the data you paste stays on your device. The few that need our server (the format converters, Object Mapper and Share Drop) process your data in memory and don't store it. See the privacy policy for details.
