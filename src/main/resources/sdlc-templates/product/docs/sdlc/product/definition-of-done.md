# Definition of Done

An item is done only when all of these are true. It's the team's shared quality bar: work that doesn't meet it
isn't shown as finished and isn't released.

<!-- FILL: your team's list. A good default:
- Acceptance criteria all pass and the product owner has seen it working.
- Code reviewed; automated tests added and passing in CI.
- No new warnings from the build, linter or security scan.
- Docs updated: user-facing help, API docs and the docs in docs/sdlc/ that the change affects.
- Works in every supported browser or device and meets the accessibility target.
- Deployed to the test environment; monitoring and alerts cover the new behaviour.
- Feature flags, migrations and config for release are in place, with a rollback plan.
-->
