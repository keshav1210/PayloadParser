# Traceability matrix

Links every acceptance criterion to its tests and their latest result, so gaps are easy to spot. The testing
commands update this table; people may edit it too.

Result: Pass · Fail · Blocked · Not run.

| Requirement | Story | Criterion | Test case | Automated test | Last result | Date | Bug |
|---|---|---|---|---|---|---|---|

## Gaps

Criteria without test cases, test cases without results, and open bugs. `/sdlc-status` and `/test-plan` list
them here.
