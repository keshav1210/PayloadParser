# Requirements

One file per feature, named `REQ-001-short-name.md`, created from `_template-feature.md`{{#if dev}} by `/requirements`{{/if}}
or copied from your tracker.
Each feature has user stories (`US-001`, …) with acceptance criteria written as Given / When / Then, so that
code, tests and bugs can be traced back to them.

Statuses: Draft → Ready → In progress → Done (or Dropped).
